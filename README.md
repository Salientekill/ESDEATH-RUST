## 🚀 Instalação

<details>
<summary>🖱️ Clique para ver o passo a passo</summary>

#### 1. Baixe e rode o instalador

```bash
git clone https://github.com/Salientekill/ESDEATH-RUST.git
cd ESDEATH-RUST
bash setup.sh
```

O `setup.sh` confere o que falta no sistema, cria as pastas e pergunta o
**nome do bot**, o **prefixo** dos comandos, o **número do dono** e o emoji do
tema. Fica tudo salvo em `dados/bot_config.json`.

#### 2. Inicie o bot

```bash
bash start.sh
```

Na primeira vez o bot pede a **chave de acesso**: cole e aperte Enter. Ela fica
guardada, e você não precisa digitá-la de novo nessa máquina.

#### 3. Conecte o WhatsApp

| Opção | Como funciona |
|---|---|
| **1. QR Code** | Escaneie o QR no terminal: WhatsApp → Aparelhos conectados |
| **2. Código** | Digite o número do bot e coloque o código de 8 dígitos no WhatsApp |
| **3. QR câmera** | QR para ler com a câmera normal do celular |

Pronto. Mande `!menu` em um grupo.

</details>

## 🔧 Comandos do terminal

| Comando | O que faz |
|---|---|
| `bash start.sh` | Liga o bot. Se ele cair, volta sozinho |
| `bash atualizar.sh` | Baixa a versão nova e reinicia. Os seus dados não são apagados |
| `bash start.sh rollback` | Volta para a versão anterior, se a nova der problema |
| `bash start.sh reset` | Desconecta o WhatsApp para conectar de novo, até com outro número |
| `bash start.sh debug` | Liga com registro detalhado, para mandar ao suporte |
